# 📌 Overview

This repository contains a collection of small interactive web applications created to consolidate and improve my front-end development skills.

Each project focuses on practical implementation rather than theory alone, covering different aspects of client-side development such as:

- semantic HTML structure
- CSS styling and interface design
- JavaScript programming
- DOM manipulation
- browser events
- conditional logic
- application state
- dynamic interface updates
- user interaction
- debugging and incremental development

The repository represents part of my broader development path as a **Software Developer and Computer Science student at the University of Salerno**.
